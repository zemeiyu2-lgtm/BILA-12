# MOS-DIS 门训同行 V1.1｜部署与内容接口

## 1. 平台定位

这是 MOS-DIS 364日门训前端基线版。

平台负责：
- 今日、本周、全年、我的
- 7日内容呈现
- 和合本经文读取
- 单项回应选择
- 今日完成记录
- 关系/伙伴入口
- 使命连接
- 本地同行进度

平台不负责：
- 重新解释经文
- 计算属灵成熟度
- 把完成度当作属灵分数
- 在前端维护第二套全年课程内容

## 2. 文件关系

`MOS-DIS_门训同行_V1.1.html`
→ 页面与交互

`bible-engine.js`
→ 本地圣经引擎

`bila-cuv-pdf-database.json`
→ 和合本逐节数据库

`mos-52w.csv`
→ 52周上位课程数据

`mos-364d.csv`
→ 364日每日内容

因此后续内容更新原则是：

**改CSV，不改页面。**

## 3. 364日内容接口

平台兼容当前中文字段，同时兼容后续正式发布CSV所需的英文兼容字段。

核心字段包括：

`day_id, week, dow, reference, day_title, core, question, choices, option_a, option_b, option_c, life_action, share, mission, fruit`

中文母库字段可以对应：

`日ID, 周次, 日序, 今日核心经文, 今日标题, 每日核心信息, 今日反思入口, 今日自我选择, 选项A, 选项B, 选项C, 今日实践, 关系/伙伴反馈, 使命连接, 生命果子`

## 4. 单选机制

每次打开一天，只允许选择一个回应。

选中后立即显示明显的选中状态，并保存到浏览器本地状态。

点击“完成今天”之前必须已经选择一个回应。

注意：

**选择的是回应方向，不是属灵等级。**

## 5. 数据与神学分离

内容母库保存完整研究字段、P/L/J证据链、神学校准、文化审核等；

发布CSV只保存平台实际读取所需字段。

这样以后可以不改平台代码，直接替换新的364日发布CSV。

## 7. Bible Engine

页面继续使用已有本地 Bible Engine 方案，不直接依赖第三方 Bible API。
当前引擎设计为从 `bila-cuv-pdf-database.json` 动态读取经文，并兼容经文简称与跨段引用。

## 8. 部署建议

把以下文件放在同一静态目录：

1. `MOS-DIS_门训同行_V1.1.html`（可改名为 `index.html`）
2. `bible-engine.js`
3. `bila-cuv-pdf-database.json`
4. `mos-52w.csv`
5. `mos-364d.csv`

浏览器打开页面前，先确认5个文件路径可访问。
